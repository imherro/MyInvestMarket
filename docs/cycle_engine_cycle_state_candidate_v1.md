# Cycle Engine v1 Phase 3.0 Candidate

This artifact is a research-only historical replay built from the frozen Phase 2 Domain Signals file. It combines valuation, earnings, and long-term trend with a fixed precedence. Macro is confirmation only, and A-FEAR remains an overlay-only field.

The candidate is not a production state machine. It does not emit numeric scores, smoothing, hysteresis, positions, allocations, recommendations, or trading signals. Forward returns and evaluation files are outside its input boundary.

The generated JSON contains the complete core-ready timeline, candidate-state distribution, transitions, rule-hit counts, macro alignment, and the requested historical windows. Its audit independently replays the precedence and verifies the frozen Phase 2 byte hash.
