# Cycle Engine v1 Feature Diagnostics

This is a descriptive, evaluation-only join between the Phase 1 Evidence
Vector and Phase 2 ex-post outcomes. It uses only model candidates, requires
both source audits to pass, and never produces scores, rankings,
recommendations, signals, regimes, weights, or positions.

It reports ready-sample Spearman correlations, fixed 0-20/20-40/40-60/60-80/80-100 rank buckets, fixed eras (2010-01..2014-12, 2015-01..2019-12, 2020-01..2026-08), and contemporaneous redundancy. Forward outcomes are descriptive and overlapping; no p-values or significance claims are emitted.

Run `python scripts/cycle_engine_feature_diagnostics.py --generate`.
